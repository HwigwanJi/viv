# VIV MCP 설치와 첫 대화

설치 에이전트에게 이렇게 요청할 수 있습니다.

> 이 저장소에서 VIV를 설치해 줘. 새 Windows 폴더에서 앱과 VIV MCP를 기동하고, 내가 쓰는 AI 앱에 연결해 줘. 휴대폰은 내 Tailscale의 설치 주소를 알려줘. 연결이 확인되면 VIV 시작하기로 진행해 줘.

## 연결

이미 VIV 서버가 켜져 있으면 저장소 루트에서 실행합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-viv-mcp.ps1
```

새 PC에서 앱과 Codex를 같이 준비하려면 [독립 설치](self-host.md)의 설치 명령에 `-CodexMcp`를 추가합니다. MCP 주소의 기본값은 `http://127.0.0.1:4317/mcp`입니다. 다른 포트를 쓴 경우 같은 `-Port`를 전달합니다. Streamable HTTP를 지원하는 다른 AI 클라이언트에서는 설정의 MCP 서버 URL에 이 주소를 넣습니다. 루프백 주소는 AI 클라이언트와 VIV 서버가 같은 기기에서 실행될 때 쓸 수 있습니다.

1. `initialize`에서 `viv`, `tools/list`에서 `viv_onboarding`을 확인합니다.
2. 새 AI 대화에 **VIV 시작하기**를 입력하거나 MCP 프롬프트 메뉴의 **VIV 시작하기**를 선택합니다. 자연어 요청을 받은 에이전트는 `viv_onboarding`을 호출해 반환된 플레이북으로 바로 시작합니다. 클라이언트가 새 대화를 스스로 열 수 없는 경우 이 시작 문장을 사용자에게 전달합니다.
3. 링크를 열 수 있는 AI 앱에서는 VIV의 결과를 인앱 브라우저에 띄웁니다. 앱이 인앱 브라우저를 제공하지 않으면 같은 결과 링크를 누를 수 있게 표시합니다. 휴대폰에서 보려면 같은 tailnet에서 서버의 비공개 HTTPS 주소를 엽니다.

## 첫 대화의 순서

| 단계 | AI가 할 일 |
| --- | --- |
| 모의계좌 | 1 주식 / 2 코인 / 3 둘 다를 받은 다음 원화 모의 예산을 묻습니다. 금액을 받으면 최초 공용 예산을 저장하고 실제 영수증과 모의계좌 링크를 보여줍니다. 기존 예산이 있으면 그 금액으로 진행합니다. |
| 튜토리얼 | “튜토리얼이 있습니다. 진행하실까요? 1 진행 / 2 건너뛰기” |
| 예제 과업 | 1 코인 시장 동향 조사·수집 / 2 유튜브 거래 기록으로 전략 초안 / 3 링크의 투자법으로 전략 초안 / 4 모의투자와 판단 브리핑 |
| 조사와 저장 | AI가 실제 원문을 읽고 MCP로 라이브러리·작성 양식·전략 노드 메타데이터를 조회합니다. 브리핑 후 어디에 저장할지 묻고, 저장을 선택하면 초안과 확인 링크를 제공합니다. |
| 이어서 하기 | 완료한 항목을 빼고 남은 번호를 보여줍니다. 다른 번호를 선택하거나 0으로 마칩니다. |
| 실계좌 | “1 지금 연결 / 2 나중에”. 지금을 고르면 VIV의 연결 화면을 엽니다. 키는 VIV 설정 화면에 입력합니다. |

실행용 프롬프트는 MCP의 `viv_start`와 `viv_onboarding` 응답에서 같은 내용을 제공합니다.
