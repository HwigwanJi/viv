# VIV MCP 설치와 첫 대화

설치 에이전트에게 이렇게 요청할 수 있습니다.

> 이 저장소의 VIV를 Windows에 원샷으로 설치해 줘. 사용할 환경을 먼저 물어보고, 내 선택에 맞춰 앱·서버·MCP를 설치하고 확인해 줘.

## 연결

새 PC에서는 [VIV 설치](self-host.md)를 먼저 실행하세요. 이미 VIV가 열리면 운영체제에 맞는 [MCP만 복구하기](self-host.md#mcp만-복구하기) 명령을 사용하세요. Claude Code는 사용자 범위에서 연결을 확인합니다.

수동 연결의 기본 MCP 주소는 `http://127.0.0.1:4317/mcp`입니다. AI 클라이언트와 VIV 서버가 같은 컴퓨터에서 실행될 때 쓸 수 있습니다. 다른 포트로 설치했다면 기존 PC 주소에 `/mcp`를 붙이세요.

1. `initialize`에서 `viv`, `tools/list`에서 `viv_onboarding`을 확인합니다.
2. MCP를 현재 대화에서 쓸 수 있으면 `viv_onboarding`을 호출해 바로 시작합니다. 연결을 다시 읽어야 하는 클라이언트에서는 새 AI 대화에 **VIV 시작하기**를 입력하거나 MCP 프롬프트 메뉴에서 **VIV 시작하기**를 선택합니다.
3. 링크를 열 수 있는 AI 앱에서는 VIV의 결과를 인앱 브라우저에 띄웁니다. 앱이 인앱 브라우저를 제공하지 않으면 같은 결과 링크를 누를 수 있게 표시합니다. 휴대폰에서 보려면 같은 tailnet에서 서버의 비공개 HTTPS 주소를 엽니다.

이 연결은 Claude Code가 실행 중인 PC의 VIV를 사용합니다. Claude 웹·모바일의 원격 커넥터는 Anthropic 서버에서 연결하므로 PC의 루프백 주소를 사용할 수 없습니다. [Claude Code MCP](https://code.claude.com/docs/en/mcp) · [Claude 원격 커넥터](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

## 첫 모의 실습

보관한 BTC 과거 시세로 백테스트를 실행하고, 어떤 판단이 나왔는지 확인한 뒤 같은 결과를 다시 열어 봅니다. AI 연결이나 모의 예산 없이 앱에서 시작할 수 있습니다.

1. 터미널의 **VIV PC** 주소 또는 설치 결과의 `desktopUrl`을 여세요. 설치 화면에서는 **VIV 열기**를 누르세요. 상단에서 **모의**를 선택한 뒤 **홈 → 첫 백테스트 실습**을 엽니다.
2. 예제로 **추세형**을 고르고 **기간 선택**을 누르세요. 화면에 제시된 기간으로 **실행 검토**를 열면 적용 정책, 초기 자금과 비용, **예상 최대 AI 호출**이 0회인지 확인하세요. 초기 자금과 비용을 바꾸려면 **상세 설정**을 여세요. 조회가 끊기면 **실행 조건 다시 확인**을 눌러 같은 조건을 조회하세요.
3. 나중에 이어가려면 **저장하고 실행 준비**까지 누르세요. 모의 홈의 **백테스트 이어하기**를 열면 같은 실험의 기간과 초기 자금, 비용을 다시 확인할 수 있습니다. **실행**을 누르면 저장한 조건으로 계산을 시작합니다.
4. **완료**가 표시되면 **성과·비교**에서 순수익률과 최대 낙폭을 확인하세요. **판단**에서 원하는 행의 **상세**를 열면 시세 기준 봉, 판단 근거와 모의 실행을 볼 수 있습니다. 저장된 판단 데이터는 상세 창의 **호출 원문**에서 **저장된 결정 원본**을 펼쳐 확인하세요. 첫 모의 실습에는 **모델 API 호출**이 0회로 표시됩니다. 상세 조회가 실패하면 같은 창에서 **다시 조회**를 누르세요.
5. 모의 **홈**의 **최근 완료 실험**을 열고 **보고서·원본**을 선택하세요. **저장 상태**가 **전체 기간 완료**인지 확인하세요. 조회가 실패하면 **다시 조회**를 눌러 같은 보고서를 여세요. 다른 실험을 열려면 모의 홈의 **전체 시뮬레이션**에서 **실험 이름 검색**을 사용하세요. 이름이 같으면 각 항목의 **테스트 기간(KST)**과 **상태**를 대조한 뒤 이름을 눌러 여세요.

### 저장 보고서 확인하기

| 확인하려는 항목 | 화면에서 볼 곳 |
| --- | --- |
| 같은 실험인지 확인 | **보고서 ID**를 이전에 열어 둔 보고서와 대조하세요. 조건을 바꿔 새로 실행한 실험에는 새 ID가 생깁니다. |
| 실행 조건 확인 | **실험 조건**에서 **실행 조건**으로 시작하는 항목을 펼쳐 요청 기간, 초기 자금과 편도 비용을 확인하세요. **보고서·원본**의 **보고서·입력·평가 원본**을 펼치면 저장한 정책과 자료 식별값을 볼 수 있습니다. |
| 보고서 파일 보관 | **JSON 내려받기**에는 고정 입력과 판단·체결·평가 기록이 들어 있습니다. **원본 식별값**은 이 JSON 파일의 SHA-256입니다. 표 형식이 필요하면 **CSV 내려받기**를 사용하세요. |

다른 탭에서 실행을 마쳤다면 **실험 작업**의 **새로고침**을 눌러 완료 보고서를 여세요. **JSON 내려받기**는 현재 화면의 원본 식별값에 해당하는 파일을 저장합니다.

완료 결과의 **이 조건으로 다시 검증**은 새 실험의 실행 검토를 엽니다. 기간과 거래 비용, 예상 AI 호출을 확인하고 필요하면 조건을 바꾸세요. **취소하고 원본으로**는 열어 둔 결과로 돌아갑니다. **새 실험 저장**을 누르면 별도 기록을 만들며 **실행**을 누를 때 계산을 시작합니다. AI를 사용하는 경우 새 실험의 호출 상한과 동의를 입력합니다. AI 호출 시 연결한 제공사의 요금이 적용될 수 있습니다.

### AI 대화에서 실습 열기

이미 AI가 연결됐다면 **VIV 시작하기**를 입력하세요. 처음에는 관심 분야와 모의 원화 예산을 답합니다. 예제로 **2 코인**, **100만 원**을 선택하거나 기존 예산으로 이어가세요. **1 진행 → 4 → 키 없이 과거 데이터로 실습**을 열면 같은 백테스트 화면으로 이동합니다. 완료 후 **방금 실행한 백테스트 결과를 튜토리얼에 기록해 줘**라고 요청하면 **튜토리얼 이어하기**에서 같은 저장 보고서를 열 수 있습니다. 같은 이름의 실험이 여러 개라면 기간이나 실행 시각을 알려주세요. [연결 복구](self-host.md#연결-복구)

### 현재 확정 시세에서 모의 판단하기

1. 완료된 기준 퀀트 백테스트의 **성과·비교**에서 **현재 시세로 모의 판단 시작**을 누르면 같은 마인드의 BTC-USDT 화면이 열립니다. 첫 대화의 **4 → 현재 시세로 모의 판단**에서도 열 수 있습니다. 종목의 결제 통화 예산이 없다면 **모의 자금 설정 → 예산 저장 후 배정**을 누르고, 해당 마인드에 사용할 금액을 입력하세요. 시세 수집 뒤 **트레이딩으로 돌아가기**로 같은 종목과 마인드에 복귀합니다. AI를 호출하는 전략에는 [AI/JEV 설정](self-host.md#자기-api-키와-계좌)이 필요합니다.
2. 준비가 되면 **결정 실행**을 누르세요. **결정 상세**에서 **저장된 모의 판단**과 연결된 **모의 체결** 건수를 확인하세요. **모델 응답 지표**가 표시되면 열어서 저장된 모델 선택 확률과 자체 확신도를 볼 수 있습니다. 개별 선택 근거가 있다면 상세에 표시됩니다. **이 판단을 기록에서 보기**를 누르면 해당 판단으로 좁혀진 기록이 열립니다.
3. 나중에 모의 모드의 **마인드 → 전체 기록**에서 종목과 마인드를 확인하고 **상세**를 여세요. AI가 제공한 저장 판단 링크를 다시 열 수도 있습니다. 기존 판단만 읽으려면 **내 모의투자 상태와 최근 판단을 브리핑해줘**라고 입력하세요.

**여기까지**라고 입력하면 튜토리얼을 멈출 수 있습니다. **튜토리얼 이어하기**로 남은 항목을 다시 볼 수 있습니다.

## 첫 대화의 순서

| 단계 | AI가 할 일 |
| --- | --- |
| 모의계좌 | 1 주식 / 2 코인 / 3 둘 다를 받은 다음 원화 모의 예산을 묻습니다. 금액을 받으면 최초 공용 예산을 저장하고 실제 영수증과 모의계좌 링크를 보여줍니다. 기존 예산이 있으면 그 금액으로 진행합니다. |
| 튜토리얼 | 처음 한 번 “튜토리얼이 있습니다. 진행하실까요? 1 진행 / 2 건너뛰기”라고 묻습니다. 번호와 자연어로 진행하거나 건너뛸 수 있습니다. |
| 예제 과업 | 1 관심 분야의 시장 동향 조사·수집 / 2 유튜브 거래 기록으로 전략 분석 / 3 링크의 투자법으로 전략 분석 / 4 첫 모의 판단 또는 과거 시세 퀀트 실습 |
| 조사와 저장 | AI가 실제 원문을 읽고 MCP로 라이브러리·작성 양식·전략 노드 메타데이터를 조회합니다. 뉴스와 전략 분석은 출처와 함께 개인 라이브러리에 바로 저장하고 브리핑에 확인 링크를 제공합니다. 사용자가 조회만 요청하면 읽기만 합니다. |
| 이어서 하기 | 0 또는 ‘여기까지’로 멈추면 다음 대화에서도 중단 상태를 유지합니다. ‘튜토리얼 이어하기’라고 하면 완료한 항목의 링크와 남은 번호를 다시 볼 수 있습니다. |
| 실계좌 | 튜토리얼을 마칠 때 응답의 `liveConnection.offer`가 참이면 한 번 “1 지금 연결 / 2 나중에”를 안내합니다. 건너뛰거나 중단했다면 요청한 모의 과업을 이어갑니다. 지금을 고르거나 직접 요청하면 실전 계좌·자금 화면을 엽니다. 나중에는 `action: defer_connection`으로 저장하고 `links.paperResume`을 엽니다. 발급 중 돌아올 때도 같은 모의 결과를 열 수 있습니다. [계좌 연결과 잔고 확인](self-host.md#계좌-연결과-잔고-확인)에 따라 준비 상태와 조회 결과를 확인합니다. |

1~3번의 저장 결과를 제공한 뒤 `viv_onboarding`에 `action: complete`, 과업 번호, 라이브러리 영수증의 `documentId`를 보냅니다. 사용자가 보기만 요청했으면 `readOnly: true`로 완료를 표시할 수 있습니다. 현재 확정 시세의 저장 판단을 실행한 4번은 `decisionId`를 보냅니다. 키 없이 완료한 기준 퀀트 백테스트는 `read_simulation_collection`에서 확인한 실험의 `simulationId`를 보내고, 응답의 저장 보고서 `openUrl`을 제공하세요. 진행·중단은 `resume`·`pause`로 기록합니다.

실행용 프롬프트는 MCP의 `viv_start`와 `viv_onboarding` 응답에서 같은 내용을 제공합니다.
